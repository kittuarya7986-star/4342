1. Linear Search

Linear Search checks elements one by one until the required element is found. It works on sorted as well as unsorted arrays.

Time Complexity
Best Case: O(1)   |   Average Case: O(n)   |   Worst Case: O(n)


#include <stdio.h>
int main() {
    int a[] = {10, 20, 30, 40, 50};
    int n = 5, key = 30, i, found = 0;

    for(i = 0; i < n; i++) {
        if(a[i] == key) {
            printf("Element found at index %d", i);
            found = 1;
            break;
        }
    }
    if(!found) printf("Element not found");
    return 0;
}


Output
Element found at index 2
